# Análise de Anúncios de Veículos nos EUA

Este projeto é uma aplicação web interativa desenvolvida em Python com **Streamlit**, **Pandas** e **Plotly Express**. O objetivo da aplicação é facilitar a Análise Exploratória de Dados (EDA) de um conjunto de dados de anúncios de vendas de carros nos Estados Unidos.

## 🚀 Funcionalidades

- **Visualização de Histograma:** Permite analisar a distribuição da quilometragem (`odometer`) dos veículos anunciados.
- **Gráfico de Dispersão (Scatter Plot):** Permite avaliar a relação entre o preço (`price`) e a quilometragem (`odometer`) dos carros.
- **Controle Interativo:** O usuário pode alternar a exibição dos gráficos em tempo real utilizando botões interativos.

## 🛠️ Tecnologias Utilizadas

- **Python 3**
- **Pandas** (manipulação de dados)
- **Plotly Express** (visualização interativa de dados)
- **Streamlit** (construção da interface web)
